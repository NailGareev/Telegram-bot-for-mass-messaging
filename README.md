# Бот для билетов с QR-кодом

Telegram-бот для администраторов мероприятия: выдаёт билеты с уникальным QR-кодом,
проверяет их на входе и ведёт список клиентов.

## Возможности

**Все администраторы**

- 🎟 **Новый билет** — ввод ФИ, группы, университета и телефона → готовый билет (PNG) с уникальным QR.
  Если на этот телефон билет уже выдавался, бот предупредит.
  На одни данные можно выдать сразу несколько билетов (до 10) — у каждого свой номер и свой QR.
- 📷 **Сканирование** — три способа:
  1. навести обычную камеру телефона на QR и открыть ссылку — бот покажет данные клиента;
  2. прислать боту фото QR-кода;
  3. ввести номер билета вручную.

  При повторном сканировании бот сообщает, что билет уже использован, и показывает время
  первого сканирования.
- 📋 **Список** всех купивших + выгрузка в TXT.
- 🔎 **Поиск** по фамилии, телефону, группе или номеру билета; повторная отправка билета.
- 🗑 **Удаление билета** — доступно главному администратору и тому админу, который этот билет выдал.
- 📊 **Статистика**: сколько выдано, сколько прошло, разбивка по админам и университетам.

**Только главный администратор**

- 👥 назначение и удаление админов;
- 🎨 смена дизайна билета: присылаете картинку → ИИ (Groq) находит место под QR →
  бот показывает предпросмотр с кнопками «Сохранить», «Сделано неправильно», «Отмена».
  Если ИИ ошибся, можно описать словами, что исправить, или задать координаты вручную;
- 🗑 полный сброс списка клиентов (перед удалением бот присылает резервную копию в TXT);
- снятие отметки о проходе.

Посторонний человек, открывший бота (в том числе гость, отсканировавший свой билет),
данных клиентов не увидит.

## Запуск

Нужен Python 3.10+.

```bash
python run.py
```

При первом запуске `run.py` создаст файл `.env` и попросит его заполнить:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `MAIN_ADMIN_IDS` | Telegram ID главного администратора (несколько — через запятую) |
| `GROQ_API_KEY` | бесплатный ключ с [console.groq.com/keys](https://console.groq.com/keys); нужен только для смены дизайна |

После этого запустите `python run.py` ещё раз — он сам создаст виртуальное окружение
`.venv`, установит зависимости и запустит бота. Все следующие запуски — той же командой.

Свой Telegram ID можно узнать, написав боту `/id` (команда работает у всех).

## Кнопка «Сканировать» с камерой

Чтобы кнопка «Сканировать» сразу открывала камеру, боту нужна страница-сканер
(`docs/index.html`), доступная по HTTPS, — так устроены мини-приложения Telegram.
Проще всего выложить её через GitHub Pages:

1. В репозитории на GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**,
   выберите ветку с кодом и папку `/docs`, нажмите **Save**.
2. Через минуту страница появится по адресу вида `https://<логин>.github.io/<репозиторий>/`.
3. Впишите этот адрес в `.env` как `SCANNER_URL=...` и перезапустите бота, затем нажмите `/start`,
   чтобы обновилась клавиатура.

Подойдёт и любой другой статический HTTPS-хостинг. Камера открывается в Telegram на телефоне;
в Telegram для компьютера на той же странице можно проверить билет по номеру.

Если `SCANNER_URL` не задан, кнопка работает по-старому: бот просит навести камеру телефона
на QR, прислать фото QR или ввести номер билета.

## Данные

База — один файл SQLite `data/tickets.sqlite3`, там же хранится загруженный дизайн
(`data/template.png`). Для резервной копии достаточно скопировать папку `data/`.

Стандартный дизайн билета лежит в `assets/default_ticket.png`.

## Замечания

- В QR зашита ссылка вида `https://t.me/<бот>?start=t_<токен>`. Если сменить username бота,
  сканирование камерой у старых билетов перестанет открывать бота, но проверка по фото
  и по номеру продолжит работать.
- Vision-модели на Groq периодически меняются. Если бот пишет, что модель не найдена,
  укажите актуальную в `GROQ_MODEL` (список — на console.groq.com/docs/vision).
- Новый дизайн лучше отправлять боту «как файл», чтобы Telegram не сжимал картинку.
